# Upstream Attribution

This private development project incorporates and modifies
SamsungHealthReporter by kvs-coder:

https://github.com/kvs-coder/SamsungHealthReporter

The original SamsungHealthReporter license is retained at:
android/SamsungHealthReporter/LICENSE

Our additions include the Android-to-Home Assistant Bridge,
background synchronization, diagnostics and HA receiver.

This is an independently created repository, not an official
GitHub fork. The precise original upstream commit is still
to be confirmed.

Samsung's proprietary Health Data SDK is not included per Samsung's rules,
but as per Samsung guidance it can be downloaded for developmenmt and 
testing use only from:

[Samsung Developer](https://developer.samsung.com/health/data/overview.html)
